Getting help
============

* Learn how to install: Installation guide (https://github.com/r4chan842/PTForge/blob/main/docs/guides/installation.md)
* Fix an error: Troubleshooting (https://github.com/r4chan842/PTForge/blob/main/docs/guides/troubleshooting.md)
* Find a function: API reference (https://github.com/r4chan842/PTForge/blob/main/docs/api/README.md) or the Functions panel in the editor
* Ask a question: Discussions tab
* Report a bug: Bug report (../../issues/new?template=bug_report.yml)
* Suggest a feature: Feature request (../../issues/new?template=feature_request.yml)
* Report a security issue: Security policy (https://github.com/r4chan842/PTForge/blob/main/SECURITY.md)

Please include your Packet Tracer version and the smallest script that shows the problem.
