End devices

IP configuration for PC, Laptop, Server, Printer and other hosts. The default port is FastEthernet0. Laptops and tablets can use Wireless0.

IPv4¶

configurePcIp(name, dhcp, ip, mask, gateway, dns, port)¶
Full IPv4 settings
setPcStatic(name, address, gateway, dns, port)¶
Static address, address may include a prefix like 10.0.0.5/24
setPcDhcp(name, port)¶
Switch to DHCP
getPcIp(name, port)¶
{ port, dhcp, ip, mask, gateway, dns, mac, ipv6, ipv6Prefix, linkLocal, ipv6Gateway, ipv6Dns, up }. Addresses that are not set are null instead of 0.0.0.0 or ::. Gateway and DNS come from the HostIp, HostIpv6 and DnsClient processes
setHostFirewall(name, enabled, port)¶
Inbound firewall
runHostCommand(name, command)¶
Type a command in the host Command Prompt

mask accepts 255.255.255.0, 24 or can be left out when ip has a prefix. When both are missing /24 is used.

configurePcIp("PC1", false, "192.168.1.10", "255.255.255.0", "192.168.1.1", "8.8.8.8");
configurePcIp("PC2", false, "192.168.1.11/24", null, "192.168.1.1");
setPcStatic("PC3", "10.0.0.5/26", "10.0.0.1");
setPcDhcp("PC4");
runHostCommand("PC1", "ipconfig /all");

dhcp can be true, false or undefined. undefined leaves the current mode untouched.

Calling list.forEach(setPcDhcp) passes the array index as the port name. Use list.forEach(function (pc) { setPcDhcp(pc); }) instead.

IPv6¶

configurePcIpv6(name, options)¶
Enable IPv6 and apply the options
clearPcIpv6(name, port)¶
Remove every IPv6 address
disablePcIpv6(name, port)¶
Disable IPv6 on the port
Option      Example              Notes
----------  -------------------  ----------------------------------
address     "2001:db8:1::10/64"  Prefix in the address or in prefix
prefix      64                   Default 64
type        "unicast"            unicast, anycast, eui64
gateway     "fe80::1"            Default gateway
dns         "2001:db8::53"       DNS server
linkLocal   "fe80::10"           Manual link local address
autoConfig  true                 SLAAC
port        "FastEthernet0"      Port name

configurePcIpv6("PC1", { address: "2001:db8:1::10/64", gateway: "fe80::1" });
configurePcIpv6("PC2", { autoConfig: true });
