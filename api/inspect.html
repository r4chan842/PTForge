Inspection

Read the live state of devices straight from the Packet Tracer API. The results are real data rather than show command text, so scripts can check them and make decisions.

Switch ports¶

getSwitchportInfo(name, port) → object¶
{ port, access, modeCode, accessVlan, nativeVlan, voiceVlan, nonegotiate, cdp, channel, up, protocolUp }
getSwitchportTable(name) → object[]¶
The same information for every switch port
getPortSecurityStatus(name, port) → object¶
{ enabled, maximum, learned, secureMacs, violations, sticky }
findSecurityViolations(name) → object[]¶
Ports with at least one violation
setPortCdp(name, port, enabled) → bool¶
Turn CDP on or off on a port
getSwitchportTable("S1").forEach(function (p) {
    if (p.access && p.accessVlan === 1 && p.up) {
        log(p.port + " is still in VLAN 1");
    }
});

Switching protocols¶

getVlans(name) → object[]¶
{ id, name, isDefault } from the VLAN database
hasVlan(name, vlan) → bool¶
Whether a VLAN exists
getStpInfo(name, vlan) → object¶
{ vlan, isRoot, rootBridgeId, bridgeId, priority, rootPort, rootCost }, VLAN 1 by default
findRootBridge(names, vlan) → string¶
The switch that is root for the VLAN, or null
getVtpInfo(name) → object¶
{ domain, modeCode, version, revision }
addStaticMac(name, mac, vlan, port) → bool¶
Static MAC address table entry
removeStaticMac(name, mac, vlan, port) → bool¶
Remove a static entry
createVlans("S1", { 10: "SALES" });
if (!hasVlan("S1", 10)) {
    showResult("VLAN 10 was not created");
}
log("Root for VLAN 1: " + findRootBridge());

Routing protocols¶

getOspfInfo(name) → object[]¶
{ processId, routerId, areas, networks, distance } for every OSPF process
getEigrpInfo(name) → object[]¶
{ as } for every EIGRP process

modeCode values are the raw Packet Tracer enum numbers. The Cisco documentation does not publish their names.
