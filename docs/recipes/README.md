Recipes
=======

Short answers to common lab tasks. Full labs live in https://github.com/r4chan842/PTForge/tree/main/examples.

- Campus switching (https://github.com/r4chan842/PTForge/blob/main/docs/recipes/campus-switching.md): VLANs, trunks, EtherChannel, STP root, security
- Routing labs (https://github.com/r4chan842/PTForge/blob/main/docs/recipes/routing-labs.md): multi site OSPF, EIGRP, static backup
- Edge router (https://github.com/r4chan842/PTForge/blob/main/docs/recipes/edge-router.md): NAT, ACL, SSH, DHCP
- Servers (https://github.com/r4chan842/PTForge/blob/main/docs/recipes/servers.md): one call per service
- Documenting a topology (https://github.com/r4chan842/PTForge/blob/main/docs/recipes/documenting.md): zones, labels, IP notes
