PTForge
=======

PTForge ist eine JavaScript-Skripterweiterung für Cisco Packet Tracer. Sie ergänzt Packet Tracer um einen Editor, ein Terminal und einen Debugger sowie um eine Bibliothek mit mehr als 380 Funktionen zum Aufbau von Topologien, zur Konfiguration von Cisco-IOS-Geräten, Servern und Hosts und zur Überprüfung des Ergebnisses.

Frühe Entwicklung. PTForge hat noch bekannte Fehler, und einige Funktionen wurden nur außerhalb von Packet Tracer getestet. Prüfen Sie die Ergebnisse, sichern Sie Ihre .pkt-Dateien und melden Sie bitte jedes Problem (https://github.com/r4chan842/PTForge/issues).
