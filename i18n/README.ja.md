PTForge
=======

PTForge は Cisco Packet Tracer 用の JavaScript スクリプト拡張機能です。Packet Tracer にエディター、ターミナル、デバッガーを追加し、トポロジーの構築、Cisco IOS 機器・サーバー・ホストの設定、および結果の検証を行う 380 以上の関数を提供します。

開発初期段階です。 PTForge には既知のバグがあり、一部の機能は Packet Tracer の外でしかテストされていません。結果を確認し、.pkt ファイルのバックアップを取り、問題を見つけたら報告してください (https://github.com/r4chan842/PTForge/issues)。
