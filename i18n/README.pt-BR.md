PTForge
=======

PTForge é uma extensão de scripts em JavaScript para o Cisco Packet Tracer. Ela adiciona ao Packet Tracer um editor, um terminal e um depurador, além de uma biblioteca com mais de 380 funções para montar topologias, configurar dispositivos Cisco IOS, servidores e hosts, e verificar o resultado.

> [!WARNING]
> **Em desenvolvimento.** O PTForge ainda tem bugs conhecidos e alguns recursos só foram testados fora do Packet Tracer. Confira os resultados, faça backup dos seus arquivos `.pkt` e [relate qualquer problema](https://github.com/r4chan842/PTForge/issues).
