PTForge
=======

PTForge 是 Cisco Packet Tracer 的 JavaScript 脚本扩展。它为 Packet Tracer 增加了编辑器、终端和调试器，并提供 380 多个函数，用于构建拓扑、配置 Cisco IOS 设备、服务器和主机，以及验证配置结果。

> [!WARNING]
> **早期开发中。** PTForge 仍有已知错误，部分功能只在 Packet Tracer 之外测试过。请核对结果，备份 `.pkt` 文件，并[报告你发现的任何问题](https://github.com/r4chan842/PTForge/issues)。
