Templates
=========

Starting points for your own labs. Copy one, change the data at the top and run it.

* `blank-lab.js`: Empty structure with the recommended order
* `campus.js`: Two distribution switches, access switches, VLANs, HSRP style gateways
* `branch-wan.js`: Headquarters with branches over serial links and OSPF
* `small-office.js`: Edge router with PAT, DHCP, wireless and a server
